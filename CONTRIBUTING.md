# Contributing

Thanks for your interest in Miabi!

Bug reports, feature requests, questions, and documentation feedback are welcome. We appreciate community involvement and feedback that helps improve Miabi.

Read the [contributing guide](https://docs.miabi.io/docs/development/contributing) for instructions on reporting bugs, requesting features, and running Miabi from source.

## Pull Requests

**External code contributions are currently not accepted.**

Pull requests from outside the maintainer team will be closed without review.

This is a temporary decision. Miabi is evolving quickly, and we currently need to maintain tight control over architectural decisions, code quality, and the separation between Community and Enterprise editions.

We may introduce a formal contributor agreement and additional contribution requirements before reopening external pull requests.

If you have identified a bug or have an implementation idea:

- [Open an issue](https://github.com/miabi-io/miabi/issues) describing the problem.
- Explain your proposed solution or implementation approach.
- Include a short patch or code snippet if it helps illustrate the solution.

Community feedback and technical discussions are always welcome, even when external code contributions are closed.

## Questions and Security

Ask questions and share ideas in [GitHub Discussions](https://github.com/miabi-io/miabi/discussions).

Report security vulnerabilities privately, as described in [SECURITY.md](./SECURITY.md).
